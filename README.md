# 🎨 Mini Photoshop

Лёгкий фоторедактор на HTML, CSS и JavaScript. Работает прямо в браузере на компьютере и телефоне — без установки и зависимостей.

## Возможности
- Открытие изображений с устройства
- Кисть, выбор цвета и размера
- Ластик и обрезка
- Поворот и отражение
- Яркость, контрастность, насыщенность
- Чёрно-белый фильтр, сепия и негатив
- Отмена и повтор действий
- Сохранение результата в PNG

## Запуск
Откройте `index.html` в браузере.

## Публикация через GitHub Pages
В репозитории откройте **Settings → Pages**, выберите **Deploy from a branch**, ветку **main** и папку **/(root)**, затем нажмите **Save**. После публикации приложение будет доступно по адресу:

https://mallens234.github.io/mini-photoshop/

Без серверов, сборщиков и внешних библиотек.
